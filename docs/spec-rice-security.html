Phase 3 · Case I · Spec v1

Rice & Food Security

Paddy phenology read out of Sentinel-1 radar — the flooding minimum, the tillering rise, the heading peak — turned into planted and harvested area and a harvest date for Java's rice bowl, and set beside BPS's own KSA figures. Radar because the crop grows under monsoon cloud, which is exactly what optical cannot see through.

I1 · The question

“Indonesia will know how much rice it harvested in March. Can we know in January?”

Rice is the most politically load-bearing number in Indonesian statistics: it decides import licences, Bulog procurement, the food-price index and, in a bad year, the national conversation about self-sufficiency. BPS produces it well — the KSA area-frame survey replaced a generation of eye-estimates in 2018 and is a genuinely good method — but it produces it after the fact, roughly two months in arrears. The gap in the market is not a better annual number; it is the same number, earlier. A crop transplanted in November is visible from orbit the week it is flooded, and a harvest date follows a transplanting date by a crop duration that temperature and water stress modulate in knowable ways. That is a forecast with roughly six weeks of lead over the official monthly release, and it is the product. The methodological demonstration underneath it — that we can detect a crop calendar through cloud, at scale, and be graded against the national statistical office — is the capability a ministry, a fertiliser distributor, a miller or a food-security programme is actually buying.

Scouted and rejected, with the evidence: IRRI's Asia lowland rice extent — CC BY-NC-SA 4.0, non-commercial. RIICE / CRISP — site returns 503/500 and CRISP is a commercial sarmap service. Zhao/Zhang 30 m S+SE Asia rice — the raster stops at 5.63 °N and never crosses the equator, so it does not cover Java at all. ESA WorldCereal v100 — it has no rice class (all 21 released files listed; phase-2's announced crops do not include rice), and its irrigation layer measured 0.09 % over Semarang/Demak/Grobogan in the middle of the wet paddy season, against 38.9 % temporary crops; the ESSD paper confirms irrigation received no quantitative validation and runs ~35 % below statistics. It must not be pitched as a paddy layer. GADM — non-commercial, rejected on sight. MCD12Q2 as an input — stuck at 2024 and structurally capped at two cycles per year, which cannot represent triple-cropped irrigated sawah. ASEAN AFSIS — the only rights statement anywhere on the site is a bare “Copyright 2017 … Rights Reserved” footer: no terms page, no reuse grant, which is worse than a restrictive licence because there is no affirmative permission. It is also a revision-lagged copy of BPS (2023 reads 53,733.52 kt where BPS now says 53,980,993 t). Kementan BDSP — reachable, with an undocumented JSON query layer, but its 2025 figures are BPS's to the rounding (11,320,986.21 ha against BPS's 11,320,986.23): a cross-check, not an independent source. FAO GIEWS — PDF only, and seven months stale on the day we checked. FAO ASIS — a flat self-contradiction: CC BY 4.0 on the GIEWS access page against license_id: CC-BY-NC-SA-4.0 in FAO's own catalogue for the same datasets. Bapanas / PIHPS price portals — under maintenance and HTTP 522 respectively, and PIHPS generates its export client-side so there is no endpoint to script.

The two licence questions that need a signature. First, BPS: the data terms are the cleanest in the set and explicitly permit commercial use — “using the data for both commercial and non-commercial purposes” — subject to citation and no implied endorsement. The WebAPI developer terms are narrower: “BPS berkomitmen pada akses gratis dan terbuka ke API kami untuk tujuan non-komersial”, and they forbid selling or sublicensing API access. The workable reading is that the numbers are fine commercially with citation and what is forbidden is reselling the pipe — so we ingest to our own store, cite BPS, and never expose or proxy the API. Second, FAO: FAOSTAT is no longer CC BY-NC-SA 3.0 IGO but plain CC BY 4.0 with an appended clause — “Datasets shall not be used for or in conjunction with the promotion of a commercial enterprise and/or its product(s) or services”. A consulting demo is precisely the edge case that clause was written for, so FAO data appears here as context only and the question is escalated rather than assumed. (FAOSTAT's REST API is in any case now gated behind a developer portal and returns 401; the bulk files still work, and the Asia regional bulk is 4.49 MiB with Indonesia inside at area code 101.)

The national rice-field map, and the honest position on it. Indonesia's official Lahan Baku Sawah layer (ATR/BPN Decree 686/SK-PG.03.03/XII/2019) is live and anonymous on BIG's service — kspservices.big.go.id/satupeta/…/MapServer/36, 1,242,551 sawah polygons — and it is the best validation surface in the country. But no licence is stated anywhere on the service, and every catalogue record for it on the national SDI portal returns a null licence field. This is the Case H concession problem again, and it gets the Case H answer: the layer is used as a view-time reference overlay and a validation comparator only — never stored, never joined into a published artefact, never redistributed — and the stored prior is the CC BY 4.0 Zenodo product instead. (Two operational notes: the SDI's HTML pages return 403 while its CKAN API answers normally with a browser User-Agent, and the separate host geoservices.bappenas.go.id did not resolve at all on 2026-08-30.)

I3 · Pipeline

Pipeline — static rebuild, scoped on purpose

The scoping arithmetic, stated because it is the design. Java needs 28 Sentinel-1 IW GRD scenes per 12-day cycle across 12 relative orbits — a figure ASF's catalogue and CDSE's OData $count return identically — and a GRD scene measures 836–847 MB. Two years of Java GRD is therefore ~1.4 TB. The same two years as OPERA RTC bursts is ~290 GB: five times smaller and already terrain-corrected. Our four-season deep scope (six kabupaten, ~9,000 km²) is roughly 50 GB of transfer, streamed and deleted after aggregation, leaving under 3 GB standing. Wall time on the 16 GB server: ingest 6–10 h (network-bound, resumable per burst), backscatter 1–2 h, phenology minutes, everything after that seconds. A full rebuild is an overnight job, not a week.

The deep scope is chosen by where the benchmark is monthly, not by where the rice is prettiest: Indramayu (239,498 ha in 2025), Karawang (202,293), Subang (184,319) in West Java, Bojonegoro (160,748) and Lamongan (152,564) in East Java — the five largest regencies in the two provinces that publish monthly KSA — plus Grobogan in Central Java as the deliberate rainfed contrast, validated annually, which is stated wherever it appears. Karawang carries a second story on its own: it is the most urbanising of the trio, so its paddy is being converted while it is being measured.

stats

Runs first on purpose. The national/provincial tables from domain 0000, then the per-province domains for kabupaten detail — because rice, unlike poverty, is not served at regency level from the national domain. Variable ids are resolved by keyword search and written to data/bps_vars.json rather than hard-coded. About 65 requests, under a megabyte, a minute. Cheap — and if the benchmark cannot be retrieved the case does not exist, so it should fail here rather than after the SAR ingest.

aux

geoBoundaries ADM1/ADM2 + COD-AB kecamatan; the Open-SEA-Rice-10 prior reprojected onto the analysis grid and dilated by 300 m so newly converted land can still be found; the cell index with geodetic areas and its kecamatan/kabupaten codes.

climate

CHIRPS dailies streamed, clipped, reduced and deleted; per-cell monsoon-onset date under a stated rule (40 mm over 10 days with no following dry spell — “onset” has a dozen definitions and they disagree by weeks); ERA5 met; ONI and DMI.

sar

OPERA RTC bursts for the deep scope, resumable per (relative orbit, acquisition date), disk-guarded, raw deleted after aggregation. Every download asserts HTTP 200 and GeoTIFF magic bytes — an invalid EDL token returns the same 302-to-login as no token, and a bare HEAD can hand back a working presigned URL unauthenticated, so the failure mode is an HTML login page written into a .tif.

backscatter

Multi-look within the 100 m cell — mean in linear power, then to dB, because averaging decibels biases every cell low by an amount that depends on its own variance and therefore looks like a real spatial pattern. Per relative orbit; incidence-angle normalisation fitted on dry-season stable targets. Resample to a 6-day grid, keep the original observation dates, flag every gap over 24 days. Savitzky-Golay smoothing, which preserves peak position — the thing this case measures — where a moving average destroys it.

phenology

Five-step detector per cell per season: VV minimum below −17 dB (sheet water) → a required VH rise of ≥4 dB within 45 days (this is what separates rice from ponds, tidal flats and reservoirs) → the following VH maximum (heading) → harvest at heading + 30 days, refined by the subsequent drop → reject any event whose defining dates fall inside a gap. Cropping intensity falls out free as cycles per year.

area

Events → hectares, apportioned to kecamatan by intersection fraction (whole-cell assignment produces visible edge artefacts on Java's small districts). Three separately-named quantities: paddy extent (a stock), harvested area (a flow, comparable to KSA), planted area (the flow that leads it). Intervals from detection confidence, mask sensitivity and gap fraction.

model

An interpretable calibration of detected → KSA hectares with cropping intensity, irrigation share and observation density as covariates, so the residual structure is visible rather than absorbed by a scale factor; then the timing predictor — harvest date from transplanting date, growing-degree-day accumulation and water stress, issued roughly six weeks ahead of the official monthly release. Fitted on 2022–24 only.

validate

Gates G-I1…G-I5 → stats.json, evaluated on the uncalibrated series as well as the calibrated one.

export

View-models ≤ 3 MB first paint. The probe lattice — quantised curves plus detected events, dates as indices into one shared array — is what makes the signature interaction instant, and its step is a config constant rather than an afterthought. Insight brief per D11.

I4 · Validation gates

Validation gates

Thresholds fixed here, before any result was seen. A gate that fails is published red with a diagnosis — the house precedent is Case C's G-C5 and Case H's G-H1, both of which shipped failing and explained. Thresholds are never moved to fit an outcome.

G-I1 — KSA reconciliation (hard). Provincial annual harvested area within ±10 % of BPS KSA for every year in the record; at kabupaten level R² ≥ 0.75 and MAPE ≤ 20 %. Evaluated on the uncalibrated series as well as the calibrated one — a gate applied only after fitting to the benchmark is not a gate. The pre-2018 eye-estimate regime is excluded: BPS itself replaced that series, and comparing against it would measure the wrong thing. Three published defects are asserted against rather than inherited: Kota Batu's 2025 “Tahunan” cell is an exact 100× decimal slip against its own monthly sum, var 2345's 2026 annual cell was never refreshed past April, and roughly 40 East Java regency-months are blank where they are almost certainly true zeros.
G-I2 — Harvest-timing accuracy (hard). Median absolute error of the modelled peak-harvest week ≤ 2 weeks, with no unit biased more than 3 weeks. Because West and East Java publish monthly KSA harvested area per regency for 2018–2025, this gate is evaluated on a 65-regency × 96-month panel — 6,240 observations — not on four provincial curves. Central Java is annual-only and is excluded from G-I2 with that stated. This is the gate that matters commercially: area we can approximately reproduce, but timing is what nobody publishes early.
G-I3 — Cropping-intensity plausibility. Detected cycles per year land in 1.5–2.5 for the irrigated lowland kabupaten and below 1.5 for the rainfed ones, and agree with Open-SEA-Rice-10's own single/double/triple classes. An independent agronomic sanity check on the detector that costs nothing extra.
G-I4 — Independent rice-map agreement. Our detected paddy extent agrees with Open-SEA-Rice-10 on ≥ 70 % of its area. Agreement is measured, not assumed — the mask is a prior, and where we differ from a published product is the interesting part. The published product's own ~6,460 km² national underestimate is carried as a stated bias, not silently absorbed.
G-I5 — Temporal hold-out. The 2025/26 season is excluded from calibration entirely and G-I1 and G-I2 are re-reported on it before any tuning. In-sample agreement with a benchmark you fitted to is not evidence.
I5 · Dashboard

Dashboard — page anatomy

Map rule: the user's browser runs with WebGL off — every map ships a full-function 2-D canvas/SVG fallback (Path2D + isPointInPath, the nightlights pattern), tagged visibly when active. In this case the fallback is not a downgrade: the maps are choropleths and point lattices, both of which canvas draws at 60 fps.

  1. Hero — “The radar probe.” signature interaction A probe drifts across an irrigated command and the panel beside it draws that location's real Sentinel-1 curves — raw VV and VH observations as points, the Savitzky-Golay fit through them — with the detected flooding minimum and heading maximum snapping into place as it moves, and the derived planting and harvest dates dropping onto a calendar strip. Then it hands the probe to the reader. It teaches the physics in one gesture, proves we hold per-pixel data rather than a downloaded map, and shows the noise the fit is drawn through — a client who can see the scatter trusts the line. 2-D fallback: this is already 2-D. Reduced motion: probe parked, curve static, drag still works.
  2. Chapter 01 — “Why radar.” Usable Sentinel-2 scenes per month over Java, counted live from the anonymous STAC, against the Sentinel-1 acquisition record on the same axis: the wet-season collapse in one chart. The argument for the whole method, measured rather than asserted.
  3. Chapter 02 — “The harvest wave.” One scrub through the crop calendar: kecamatan recolour by phenological stage on the cyclic ramp while the national harvested-area ridge fills beneath and the wave visibly crosses the island. Staggered planting is what makes Indonesian rice supply continuous, and this is the only view that shows it as motion.
  4. Chapter 03 — “Our number against theirs.” Radar-derived harvested area beside BPS KSA — per kabupaten, per month — with the residuals charted rather than netted out and the calibration's coefficients shown. The 2018 break is drawn as a break: 14,116,638 ha in 2015 under the old method, a two-year moratorium with no data at all, then 11,377,934 ha in 2018 under KSA — a 2.74 Mha, −19.4 % step across a hole, which is why no line may cross it. And the chapter ends on the claim worth stress-testing: 2025 harvested area jumped +1,274,851 ha (+12.7 %) in a single year, with Java supplying about half of it (Jawa Barat +19.0 %, Jawa Timur +13.9 %). An independent measurement either corroborates that or it does not, and either answer is worth the build.
  5. Chapter 04 — “The calendar is moving.” Planting-date anomalies against monsoon onset, ONI and DMI: when the rain is late, the crop is late, and the harvest lands in a different month than the procurement plan assumed.
  6. Chapter 05 — “Six weeks early.” The hold-out season replayed as it would have been issued: our forecast at transplanting, then the official figure arriving weeks later on the same timeline. The product, demonstrated rather than described.
  7. Explore. Probe anywhere; kabupaten panel (planted/harvested/extent with intervals, cycles per year, confidence, KSA comparison); stage filter, season toggle, orbit-diagnostic view; URL state; chart/table + download.
  8. Methodology. Speckle and the linear-power rule; orbit separation; the detector's thresholds and why each exists; the flow-vs-stock definition; every gate result; the KSA methodology break; the Lahan Baku Sawah licence statement verbatim; attributions (Copernicus, ASF/OPERA, BPS, Zenodo products, CHC, ECMWF, geoBoundaries, OCHA).

I6 · Design brief

Design brief

Identity: flooded paddy, seen by radar. The accent is a young-paddy chartreuse at roughly 78° of hue — the one green-adjacent slot the other eight cases leave open, with forest's canopy green at ~133°, far enough that the two never read as the same case. The phenology ramp is cyclic, because a crop calendar is a loop and a linear ramp would imply a beginning and an end that the data does not have: flood teal → vegetative green → heading chartreuse → ripening gold → harvest stubble → back to flood. The ramp is data-only and never doubles as the accent; official BPS series always appear in the site-wide --official teal so that “ours” and “theirs” are never the same colour.

I7 · Acceptance

Acceptance checklist

  • make rebuild reproduces phenology → area → model from raw sources on a clean machine given an Earthdata token and a BPS key (gate 1).
  • G-I1…G-I5 evaluated and published, on the uncalibrated series as well as the calibrated one (gates 2–3).
  • Probe responds < 300 ms; explore interactive < 3 s; per-tile probe files ≤ 2 MB; 60 fps; Lighthouse ≥ 90; full function with WebGL disabled (gate 4).
  • Vintage stamps: OPERA RTC granule dates · BPS release date and table id · Open-SEA-Rice-10 2021 · CHIRPS/ERA5 cutoffs (gate 5).
  • Attributions incl. the Copernicus line and the BPS line; the Lahan Baku Sawah licence statement verbatim; no NC data anywhere — IRRI, GADM and the WorldCereal RDM collection all held out pending or refused (gate 6).
  • Story reads in one scroll; the probe passes the award test (gates 7, 9).
  • Static hosting; the only credentialed calls are at build time; no per-view API cost (gate 8).
I8 · Risks & decisions pending

Risks, unknowns & decisions pending user verification

  • 30 m against a 0.3–0.5 ha plot. OPERA RTC is 30 m, so a Javanese sawah plot is a handful of pixels and mixed pixels dilute the flooding minimum — biasing detection toward the larger, more uniform irrigated blocks. The mitigation is the 10 m Sentinel Hub close-up on one regency, which is also the honesty panel: the same kabupaten measured at both resolutions, differences shown. This is the case's only registration ask (one free CDSE account).
  • OPERA's recent months are thin. Processing latency, not a coverage gap — CMR shows 2016 acquisitions processed in September 2025, i.e. an archive backfill still running. For a historical four-season build it is dense and reliable; do not promise a near-real-time OPERA feed without re-checking, and the “six weeks early” chapter is framed on the hold-out season rather than on today.
  • The detector's thresholds are literature values, not fitted. −17 dB, 4 dB, 45 days, 30 days. Fitting them on the KSA benchmark would guarantee agreement and destroy the gate. They are stated, and the sensitivity of every headline number to each of them is exported.
  • MODIS is on a clock. Terra and Aqua begin shutting down in late 2026/early 2027 and are already drifting from their design overpass times, injecting an illumination bias that mimics a phenological trend. MODIS therefore appears only as a labelled comparison; VIIRS (VNP13A1/VNP22Q2) is named as the successor.
  • CHIRPS v2 dies in four months. Production ends after December 2026, so pinning v2 would pin a product that stops updating mid-engagement. The config builds on v3, which deserves its own reconnaissance pass before the first long run since only its directory existence was confirmed.
  • The best possible ground truth exists and is almost entirely unpublished. KSA's own phase classification — vegetatif awal/akhir, generatif, persiapan lahan, puso — is exactly the label set a satellite phenology model wants, and BPS publishes it through the WebAPI for DKI Jakarta only, 2018–2021, a province with almost no rice. Everywhere else it is absent. A direct data request to BPS is the single highest-value action available to this case, and it costs nothing but a letter.
  • Pending user verification: (1) the [data-case="rice"] token block, which this spec's author was scoped out of adding; (2) scope — Java's rice-bowl provinces, six deep kabupaten chosen by where the benchmark is monthly, the biggest call in the case and the one that keeps it honest; (3) analysis units — detect at 100 m, map at kecamatan, report and validate at kabupaten, so that G-I1 stays falsifiable; (4) the Lahan Baku Sawah compromise (validation and view-time overlay, nothing stored) — the direct analogue of Case H's concession decision; (5) the BPS licence split — data terms permit commercial use with citation, developer terms restrict the API — so we ingest to our own store, cite BPS, and never proxy the API; (6) FAO's anti-commercial-promotion clause, which makes FAO context-only here; (7) whether the WorldCereal RDM ground-truth collection may be used at all, pending its licence; (8) publishing “production = our area × BPS productivity” as arithmetic, given how politically live that number is.
  • Out of scope: yield modelling from backscatter, national coverage, non-rice crops, irrigation-infrastructure mapping, and any claim about Bulog procurement or import policy. Each is a plausible paid-pilot extension and is noted in the CTA rather than half-built.
