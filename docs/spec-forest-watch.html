Forest & Commodity Watch

Where Global Forest Watch stops: weekly radar alerts clustered into disturbance events and linked to what the land becomes — oil-palm extent, mill catchments, peat and primary forest — so an alert stops being a pixel and becomes a supply-chain question. National alert ledger; deep dives in Riau, Kalimantan Tengah, Papua.

H1 · The question

“The forest moved last week. Whose supply chain did it move into?”

GFW already shows Indonesian deforestation at maturity — repeating it would prove nothing. What GFW's public dashboard does not do is turn alerts into commodity context: was this clearing inside an existing palm estate, on its edge, inside a mill's supply catchment, on peat, in primary forest? That linkage — the question EUDR compliance teams, traders and NGOs actually ask — is buildable entirely from CC BY 4.0 layers (RADD + Descals palm map + Universal Mill List + peat + Margono primary forest), and it is the deliberate reframe recorded in the build plan's portfolio row (“reframe toward concession-linkage analytics GFW doesn't do”).

The concession problem (load-bearing honesty): there is no commercially-licensed, redistributable Indonesian concession vector. GFW's API marks its concession sets “CC BY 4.0 excluding Indonesia (view-only)”; the Hub's Indonesian items are 2010-era MoF data with no licence; the ministry's own services (geoportal.planologi.kehutanan.go.id PBPH MapServer, SIGAP WMS) are publicly queryable but carry no licence text, and RSPO notes Indonesian law bars non-government publication of estate boundaries. Therefore: concession outlines appear only as a live, labelled reference overlay rendered from the government's own services at view time — never stored, joined, or redistributed — and the stored linkage uses palm extent + mills + peat/primary instead. Rejected: Nusantara Atlas (non-commercial), GeoRSPO (no open licence · IDN excluded), Sentinel-1 RTC own-processing (no anonymous source).

H3 · Pipeline

Pipeline — static core + weekly alert refresh

Raw pull ≈ 7–8 GB once (Hansen dominates), ≈ 1 GB per weekly refresh (latest RADD version tiles). Wall time on the 16 GB server: ingest 1–2 h; alerts pass ~1–2 h nationally (windowed reads, one 10° tile never in RAM whole, peak ~2 GB); link minutes; chips ~30 min. Weekly refresh < 30 min end-to-end.

ingest

Hansen tiles (3 layers × 14), latest RADD + GLAD-L versions via the API key, Descals palm extent + planting year, UML CSV, peat + primary rasters, COD-AB. Manifest with dataset versions — every downstream artefact carries the RADD version string.

alerts

Decode date_conf → weeks; mask to treecover2000 ≥ 30 % + land; 8-connected components over rolling 4-week windows → clusters ≥ 0.5 ha; per cluster: dates, ha, high-conf share, centroid, GLAD-L agreement flag (±60 days). National weekly ledger + per-province cluster tables.

link

Cluster typology — PALM-INTERNAL (replanting/expansion inside the 2021 extent, dated by planting-year) · PALM-EDGE (≤ 1 km) · MILL-CATCHMENT (≤ 50 km of a UML mill, the Trase FFB radius) · UNLINKED — plus on-peat and in-primary-2000 flags. Per-mill “alert pressure” score (distance-weighted ha, trailing 12 months). Concessions deliberately absent from storage (H2).

chips

Sentinel-2 before/after pairs for the top 20 clusters per focus province (90-day windows, < 40 % cloud, skip-and-say-so when the monsoon wins); ≤ 60 kB PNGs with the cluster outline burnt in.

validate

Gates G-H1…G-H4 → stats.json; includes the KLHK-vs-GFW definitional divergence panel (1.12 Mha TCL vs 175.4k ha net deforestation for 2024 — both true, different definitions).

export

View-models ≤ 3 MB (province ledgers, cluster points, mill scores, linkage-class shares per quarter); weekly refresh re-exports alerts + links only. Insight brief per D11.

H4 · Validation gates

Validation gates

G-H1 — Hansen reconciliation (hard). Our per-province tree-cover-loss hectares (≥ 30 % canopy) vs the GFW query API over the same COD-AB geometry: within ±5 % for every year 2015–2024. National anchors from GFW's own country table: 2023 = 1,395,285 ha, 2024 = 1,120,264 ha (primary-forest loss 292,374 / 258,812 ha). Same source data — this gates our raster plumbing.
G-H2 — Alert reconciliation (hard). Our RADD count + hectares per focus province, trailing 12 months, vs the GFW API's aggregation over the same geometry: within ±10 %; residual differences (forest mask, 0.5 ha cluster floor) quantified in the methodology, not waved at.
G-H3 — Two-sensor agreement. ≥ 60 % of high-confidence RADD clusters ≥ 5 ha carry a GLAD-L alert within ±60 days. Radar and optical agreeing is the trust argument for radar-first monitoring under cloud.
G-H4 — Linkage sanity. Palm+mill-linked share of alert hectares in Riau ≥ 25 % — the literature floor (Gaveau 2022: ~32 % of 2001–19 loss directly to palm; Trase: palm-driven share declining since the 2012 peak). If it lands below, the radii and masks are diagnosed before publish — never tuned to pass.
H5 · Dashboard

Dashboard — page anatomy

Map rule: the user's browser runs with WebGL off — every map ships a full-function 2-D canvas fallback (Path2D + isPointInPath, the nightlights pattern), tagged when active.

  1. Hero — “Fifty-two weeks of alerts.” Signature moment: a focus province in deep canopy green; the year's alert clusters ignite week by week in burnt umber, a HUD counting hectares, then the frame exhales into the linkage split (linked / unlinked). 2-D fallback: the ignition pre-rendered as weekly canvas frames with a scrubber. Reduced motion: final frame + totals.
  2. Chapter 1 — “Two decades of loss.” Hansen 2001–2024 province small multiples; the GFW-vs-KLHK definitional divergence chart with the plain-words explanation — the honesty move, up front.
  3. Chapter 2 — “The alerts.” How radar sees through cloud (Reiche 2021: 97.6 % user's accuracy, 74 % confirmed within 24 days); weekly ledger with the GLAD-L agreement band; the G-H2 reconciliation shown as a chart.
  4. Chapter 3 — “Linked or unlinked.” The payoff: linkage-class shares per province per quarter (stacked areas); PALM-INTERNAL vs frontier split; on-peat and in-primary flags as the EUDR framing.
  5. Chapter 4 — “The mills.” Mill map sized by alert pressure; group/parent names as published in the UML; Trase kabupaten context. The overlay toggle brings in the government concession services, labelled “reference overlay — official services, no open licence”.
  6. Explore. Cluster map (points, class-coloured) with week scrubber; click → panel (dates, ha, flags, nearest mills, before/after chips); layer toggles (palm, peat, primary, mills, concession overlay); URL state; chart/table + download.
  7. Methodology. Alert decoding + masks; cluster rules; linkage definitions and their radii; every gate result; the concession-licence statement verbatim; attributions (WUR/GFW line, UMD/Hansen, Descals, UML, Trase, Copernicus, COD-AB).

H6 · Design brief

Design brief

Identity: canopy against burn. Deep forest ground; canopy green is structure and “intact”; burnt umber (--loss) is reserved exclusively for loss and alerts — green never means alert, umber never means UI. Linkage classes step umber → ochre; peat and primary flags are outline treatments, not new hues.

H8 · Risks & decisions pending

Risks, unknowns & decisions pending user verification

  • GFW API key dependency — free but expires yearly (calendar item, like the Earthdata token) and rate-limit tiers are undocumented; mitigations: all downloads resumable by version, and G-H1/G-H2 queries are one-shot per rebuild.
  • Palm extent is 2021 — alerts from 2022+ on younger estates read as “frontier”; the planting-year raster bounds the error and the methodology says it; a Descals refresh would slot in unchanged.
  • RADD false positives in swamp forest (GFW's own caution) — the peat flag doubles as the caveat trigger; high-confidence-only counts shown beside totals.
  • “Global Nature Watch” rebrand — GFW's citation line now names GNW; endpoints may migrate. The dataset slugs are pinned in config and the manifest records the API host per pull.
  • Pending user verification: (1) the concession-overlay compromise (view-time government services, nothing stored) — the single biggest editorial call in this case; (2) naming mills/groups from the UML on a public page (fields are published CC BY 4.0, but a Jakarta consultancy may prefer aggregation to group level); (3) the weekly refresh cron vs D3's static rule; (4) Papua = pre-2022 province boundary from COD-AB 2020.
  • Out of scope: own Sentinel-1 change detection, carbon/emissions accounting, trader-level flows beyond Trase's published aggregates, KLHK SIMONTANA replication.
