1 · Known defects, cleared first

The four defects called out before the pass began — all on the global-narrative page.

Hero anchor annotations collided and overran the plot Criticalglobal-narrative

At 1440px the nine dated captions were staggered by a fixed 330px assumed width, so they read as a floating slab of text; at 390px they ran clean off the left edge — four of them rendered as “ake & tsunami”, “akatau tsunami”, “n riots, Jakarta”, “0-19 cases announced”.

captions are now measured from their own string length, clamped inside the plot, and assigned the first stagger row their true interval clears; each is joined to its dot by a leader with a horizontal jog where clamping moved it. Below 760px the plot switches to numbered markers and the captions move to an ordered key beneath the chart, which removes the clipping entirely rather than shrinking type to hide it.

22 text elements rendered below 12px Criticalall five pages

A full sweep found far more than the reported 22: 187 sub-12px text nodes across the five pages, down to 9px. Sources were .stamp, .eyebrow, chips, table headers, toggles, verdicts, tooltips, SVG annotations, canvas fillText calls and one hard-coded font-size="9".

every declaration below the floor raised to ≥12px on all five pages, including the canvas and SVG paths that a CSS-only sweep would miss. Verified 0 remaining sub-12px nodes at both viewports.

“LOADING THE PULSE…” outlived the render Highglobal-narrative

The status line was only rewritten in the completion callback of a 5.2-second animated wipe, so for five seconds the page claimed to be loading a chart the reader could already watch drawing itself.

the headline figures publish the moment the data is in hand, before the wipe starts. The pending state is now reachable only when data is genuinely absent, and it was redesigned — a spinner and a framed panel rather than a bare grey line.

Dead space across the right half of the hero Highglobal-narrative

Copy was capped at 40rem in a single left column, leaving roughly 45% of the hero empty above the chart — and the page had no big-stat display moment anywhere.

the hero is a two-column grid; the right column carries four figures — days observed, peak share, decade mean, anchor events — built from the exact numbers that were already in the status line. On mobile they stack 2×2 under the copy.

2 · Found during the audit

Additional findings from screenshotting every page at both viewports.

Era band labels overprinted into an unreadable smear Criticalglobal-narrative

At 390px the five era labels on the hero collapsed on top of one another, rendering literally as “ASEANECHARDABOWEARA”.

a band label is now drawn only where its own band is wide enough to hold it; narrow bands stay unlabelled and are separated by a tinted rule instead. The eras chapter immediately below names all five.

Ten console errors on a GPU-off browser Criticaltrade-complexity

The 2-D canvas fallback was already correct and looks excellent, but THREE.WebGLRenderer logged ten console errors on the way to throwing — which is precisely what the owner's own browser produces, on the path they actually see.

probe for a WebGL context before constructing the renderer and go straight to the 2-D path when there is none. A GPU-off browser is a supported configuration here, not a fault worth shouting about.

Horizontal body scroll at 390px Highglobal-narrative

The document was 404px wide in a 390px viewport, so the whole page rocked sideways under a thumb.

responsive hero breakpoints at 900px and 640px, plus a max-width guard on the document. Verified no horizontal scroll on any of the five pages at 390px.

Long chart legends clipped against the plot edge Highglobal-narrative

Descriptive legends were drawn as single unwrappable SVG <text> nodes inside the plot. The methodology chart's legend measured 1,194px inside a 342px-wide plot — most of it invisible.

a legend is a caption, not a datum. The four longest now render in the document flow with colour swatches, wrapping to the container at any width and selectable as text.

Treemap names spilled over neighbouring tiles at the 12px floor Mediumtrade-complexity

Raising small-cell labels from 10.5px to the floor made long sector names overflow their rectangles.

a name too long for one line wraps to a second (with the share figure pushed down to match) and is dropped only if it still will not fit; “Gems & gold” stayed legible and nothing spills.

Calibration figures sat on ragged baselines Mediumnightlights-pulse

Once labels wrapped to two lines at the larger size, the four big figures no longer aligned, so the row read as four unrelated boxes rather than one set of display moments.

subgrid puts label, figure and note on a shared baseline across all four tiles however many lines each label wraps to; flat surface fills replaced with layered gradients.

Case cards had no focus ring, no depth on hover, no entrance Mediumlanding page

Keyboard users got no visible focus target on the primary navigation of the whole site, and the cards lifted on hover without any accompanying light.

focus-visible rings, an accent glow and deeper shadow on hover, and an IntersectionObserver entrance reveal. The hidden state is applied by script only after it runs and a 4s failsafe forces every card visible, so a JS failure can never blank the gallery; reduced-motion skips the animation.

4 · Deliberately left alone

Jakarta and nightlights heroesno change

both already clear the bar. Nightlights runs a full-bleed Black Marble timelapse with a ticking year counter and progress ticks; Jakarta runs a full-bleed subsidence map with a −32 cm display figure and a scroll cue. Sharpening beat rebuilding here — neither was touched beyond the type floor.

Token fileshared/design

all six copies of tokens.css were already byte-identical and the per-case identities are well judged. Every fix landed in page-level CSS instead, so the copies stay in sync with no fan-out risk while four other case pages are being built against them.
