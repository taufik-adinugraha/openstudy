Indonesia in the Global Narrative

N1 · The question

“When the world talks about Indonesia — how much, how warmly, and about what?”

Every strategy, IR, and communications team asks this; almost none can answer it beyond anecdote. GDELT machine-reads the world's news every 15 minutes. This case distils that firehose into signals with the discipline of the GPR index: attention as a share of everything monitored (never raw counts — the crawl's size swings 2–3× across years), tone with honest error bars, and event types from a deduplicated event stream. Decisions: D20 no BigQuery — open feeds only; D21 hybrid architecture; D22 one shared window, 2017→now.

N3 · Pipeline

Pipeline — backfill + refresh, on the dev server

curves

A battery of ~40 cached DOC-API queries (overall attention, foreign-only, TimelineTone, per-theme timelines — PROTEST, ECON_*, ENV_*, CYBER, ELECTION —, TimelineSourceCountry), 2017→now, one request per ~12 s with backoff; JSON cached under data/raw/api/; nightly refresh re-pulls only the trailing window.

events

Stream the 15-min export zips (both feeds) 2017→now from the masterfile list: download → count global rows (denominator) → keep rows where ActionGeo='ID' OR Actor1/2='IDN' → append Parquet → delete zip. ~45 GB through the pipe, ~2 GB kept, disk never above a few hundred MB of temp. Resumable by file timestamp.

analyze

Daily series: attention share (API + own-denominator event share), tone, event typology (QuadClass conflict/cooperation, protest counts), Goldstein-weighted intensity, foreign-vs-domestic press split, top themes per era, source-country league table. Deduplication: unique events only (mentions kept solely as prominence weights) per Wang et al. 2016.

validate

Gates G-D1…G-D4; results to stats.json.

export

Web view-models (decade waveform with anchor annotations, era summaries, theme stacks, source-country matrix, event scatter) + insight brief per D11.

refresh

Cron: nightly API trailing pull + hourly lastupdate.txt events append (~12 GB/yr). The site’s vintage stamp shows both clocks.

N4 · Validation gates

Validation gates

G-D1 — Normalization honesty. Every attention chart is a share, never a raw count. The raw-count curve is shown once, in the methodology, next to the normalized one — with the 2–3× crawl-size drift called out as the reason.
G-D2 — Anchors. The pipeline must reproduce, unprompted: the 2019-05-22 protest-theme spike (~5× baseline — already live-tested), Kanjuruhan 2022-10-02 as its quarter’s most negative tone day (tested), the 2024-02-14 election and 2024-06 PDNS attention spikes, Palu 2018 and the Aug–Sep 2025 protests. Explicitly not claimed: a G20-Bali positive-tone spike — tested and absent (Ukraine coverage entangles it); the methodology says so.
G-D3 — Two-source coherence. Daily Indonesia attention from the event layer (own denominator) correlates with the API’s normalized volume, Spearman ρ ≥ 0.6 over the shared window; divergences diagnosed (feed composition, dedup) before publish.
G-D4 — Language honesty. Foreign-vs-domestic and translated-vs-English shares are surfaced, so no chart silently equates “the world’s narrative” with “the English-language narrative.”

Dashboard — page anatomy

  1. Hero — “The pulse.” Signature moment: the decade waveform of world attention to Indonesia draws itself left to right in signal violet, anchor events flaring as it passes them (reduced motion: static with annotations).

N7 · Risks & out of scope

Risks & out of scope

  • API throttling / IP blocks — observed 429s; mitigations: ≥10 s spacing, exponential backoff, cache-first design, and the event layer as an independent fallback for attention curves.
  • Crawl drift — handled by normalization (G-D1); never compare raw counts across years.
  • Automated-coding noise — event types are machine-labeled; counts are indicative, framed as such (Wang et al. 2016 cited).
  • Out of scope: full GKG mirror, sentiment beyond GDELT tone, social media, per-outlet bias modeling, pre-2017 curves (events-only before then, not shown by default per D22).
